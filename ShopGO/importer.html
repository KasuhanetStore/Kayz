KasuhaNET · ShopGO Product Importer

Import katalog produk ke ShopGO. Akaun SalesHero kekal dalam browser pembekal; jangan masukkan password di sini.

Langkah 1 · Ambil katalog SalesHero

1
Buka portal SalesHero dan log masuk seperti biasa: SalesHero B2B.
2
Di halaman katalog, buka menu browser dan gunakan alat pembaca katalog yang telah disediakan oleh pentadbir. Pengekstrakan hanya membaca produk yang dipaparkan dalam sesi akaun anda.
3
Muat turun data produk sebagai fail JSON, kemudian pilih fail itu di bawah.

Nota: versi pertama menggunakan fail JSON perantara kerana portal pembekal berada pada domain berasingan dan tidak membenarkan laman KasuhaNET membaca sesi log masuk secara terus.

Langkah 2 · Semak dan import

Belum ada fail dipilih.
Menunggu tindakan.

Format data yang diterima

Fail JSON perlu mengandungi array produk atau objek dengan medan products. Setiap produk boleh mengandungi name, sku, image/image_url, price/wholesale_price, category, description dan stock.
