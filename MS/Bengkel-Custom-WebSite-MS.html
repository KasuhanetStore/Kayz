Servis Setup & Deployment

BENGKEL WEB CUSTOM

Selamat datang ke kasuhanet.store! Jika anda ingin membina atau menaik taraf website, kami menyediakan servis setup dan deployment yang telus mengikut keperluan serta bajet anda. Anda bebas memilih kaedah pembelian dan pemasangan yang paling sesuai.

✓ Pilihan Setup & Servis
PILIHAN 01

1. Servis Setup Sahaja (Caj Mengikut Servis)

Sesuai untuk: Anda yang sudah mempunyai alatan/aset sendiri seperti Domain, Source Code/Script, VPS/Hosting atau akaun Developer.

Cara kerja: Anda sediakan alatan/aset, manakala kami uruskan pemasangan, konfigurasi dan setup sehingga website anda sedia untuk dilancarkan.

Caj: Dikira berdasarkan servis individu yang anda pilih.

PILIHAN 02

2. Pakej Lengkap (Termasuk VPS & Tools)

Sesuai untuk: Anda yang mahukan penyelesaian lengkap tanpa perlu mengurus konfigurasi teknikal sendiri.

Cara kerja: Kami sediakan alatan penting termasuk penyediaan VPS dan tools sokongan, serta mengurus pendaftaran dan setup akaun untuk anda.

✓ Panduan Harga "Bengkel Web Custom"

Mahukan pilihan yang lebih fleksibel mengikut bajet? Terokai bahagian Bengkel Web Custom kami!

Setiap servis disenaraikan secara terperinci supaya anda boleh memilih keperluan sahaja pada kadar harga pasaran tempatan yang kompetitif.

1. Pengurusan Domain & DNS Routing
Setup domain ke server/VPS atau selesaikan masalah rekod DNS seperti MX, TXT, SPF dan DKIM.
RM 50
2. Pemasangan & Setup Server / VPS
Pemasangan asas web server (Nginx/Apache), Control Panel (aaPanel/CyberPanel/cPanel) dan konfigurasi keselamatan asas.
RM 120
3. Konfigurasi Sijil SSL (HTTPS)
Pemasangan dan pengaktifan sijil SSL untuk sambungan pelayar yang selamat dan disulitkan (ikon mangga).
RM 50
4. Setup CMS & Custom Script / Source Code
Pemasangan WordPress/CMS atau muat naik dan konfigurasi script web custom (PHP, Laravel, CodeCanyon) ke server.
RM 150
5. Setup & Migrasi Database
Penyediaan database (MySQL/MariaDB), import/export data dan pembaikan ralat sambungan database.
RM 100
6. Integrasi Payment Gateway Tempatan
Sambungkan website kepada sistem pembayaran automatik seperti ToyyibPay, Billplz, Chip atau SenangPay.
RM 150
7. Setup Emel Rasmi Domain
Konfigurasi emel perniagaan menggunakan domain sendiri (Google Workspace/Zoho/Private Email) termasuk tetapan anti-spam.
RM 100
8. Troubleshooting & Pembaikan Ralat
Membaiki masalah teknikal seperti 500 Internal Server Error, 502 Bad Gateway atau White Screen of Death.
RM 100
9. Pembersihan Malware & Keselamatan Web
Imbasan sistem penuh, pembersihan kod berbahaya/malware dan pemulihan website yang digodam atau disenarai hitam.
RM 250
10. Optimasi Kelajuan & Prestasi
Meningkatkan kelajuan loading website, optimasi database/imej dan integrasi Cloudflare CDN.
RM 150
11. Migrasi Penuh Website & Server
Pemindahan keseluruhan fail website, database dan emel daripada hosting/server lama ke server baharu dengan gangguan minimum.
RM 200
12. Integrasi Analytics & Tracking Pixel
Pemasangan dan konfigurasi Google Analytics, Google Search Console, Meta Pixel atau TikTok Pixel untuk tujuan penjejakan.
RM 80
13. Upgrade Blogspot / Platform Custom
Naik taraf paparan asas Blogger/Blogspot kepada struktur profesional dengan domain custom dan kemas kini reka bentuk.
RM 120
14. Reka Bentuk Halaman (HTML/CSS/JS)
Reka bentuk landing page atau halaman tunggal menggunakan kod HTML/CSS/JS responsif yang dioptimumkan untuk peranti mudah alih.
RM 180
